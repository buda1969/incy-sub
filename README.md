# INCY Europe subscription

Публичная автообновляемая подписка для INCY на основе открытого проекта
`igareck/vpn-configs-for-russia`.

## Файлы подписки

- `mobile.txt` — до 12 европейских VLESS-узлов.
- `full.txt` — до 50 европейских VLESS-узлов.

Обновление запускается GitHub Actions каждые 6 часов и вручную через
**Actions → Update subscriptions → Run workflow**.

## Ссылка для INCY

После загрузки файлов в репозиторий замените `GITHUB_USERNAME` своим логином:

```text
https://raw.githubusercontent.com/GITHUB_USERNAME/incy-sub/main/mobile.txt
```

Эту же ссылку можно добавить на нескольких принадлежащих вам устройствах.

## Важно

Это публичные конфигурации третьих лиц. Репозиторий не создаёт собственные
VPN-серверы и не гарантирует доступность, конфиденциальность, скорость либо
одновременную работу конкретного узла на нескольких устройствах.
